Exercício de Treino

Tags Básicas:

Apenas um treino para não perder o costume e não esquecer as tags
Então vamos revisar as principais tags aprendidos aqui:
Só até aqui ja foram utilizados alguns códigos ,
1- O <pt-br> (para por em português).
2- O <title> que escrevi "Treino" (para ficar marcado na pasta e na barra de pesquisa).
3- <h1> Para por em letras grandes o título "Exercício de Treino".
4- <p> Para escrever esse texto todo que está informando as tags utilizadas até aqui.(Parágrafo)
5- Ultimo e não menos importante, o <br> para acabar um verso e começar um novo na linha de baixo.
Esses foram as principais tags aprendidas e utilizadas até aqui.

Novos Comandos:

Recentemente tivemos novos Comandos aprendidos .
1- Foram para por emojis, que já tem uma pasta explicando como se faz.
2- Como editar o tamanho das imagens, para diminuir o tamanho do arquivo para o site não ficar muito pesado.
3- Como por ícone na barra de pesquisa na parte de cima de um site, como está nessa página o símbolo do Bluetooh.
4- Como por "Título", "Subtítulo", etc.


Tags utilizadas para fazer os comandos aprendidos:

1- Já foi explicado.
2- Para mudar o tamanho do arquivo da imagem é necessário utilizar o app , Gimp.
3- Para por o Ícone na barra de pesquisa como nessa página está o símbolo do Bluetooh, é necessário, escolher a imagem do ícone no Google ou feita por alguem, baixar a imagem, ir no site "favicon.io" para transformar a imagem em Ícone, após isso ir na parte em cima do comando <title> que normalmente fica na linha 6, usar a tag <link>, escolhe o link favicon e colar o link do arquivo do ícone.
4- Para por títulos, Subtítulo etc, é necessário usar a tag <h2> <h3>, e assim por diante até o o 6. (imagem de exemplo na pasta "ex006")
