Como aprendido agora, podemos colocarr links para ir até algum lugar, mas se colocarmos só o link, quando a pessoa for entrar a sua aba do seu site será "apagada" pela do site do link, e para isso nao acontecer é necessário usar depois do link a tag target e dentro das aspas a tag _blank e depois a tag rel e dentro das aspas a tag external, para quando clicarmos no link abrir uma nova aba do site do link e a sua do seu site não ser apagada. Para entender melhor clique no primeiro link para ver como é colocando as duas tags depois do link e depois clique no segundo que está sem para ver a diferença.
